## 功能

- 隐藏指定 YOYO 唤醒覆盖层，应用操作尝试在不可见离屏显示中运行。
- 保留媒体声音，同时与 YOYO 正常对话。
- 处理首次解锁后再次锁屏时的 YOYO 任务限制，包括微信应用控制的额外解锁策略。
- 微信明确询问发送确认时，尝试内部自动语音应答一次，不从扬声器播放。

## 验证与适配

HONOR PTP-AN10，系统报告 Android 17 / API 37，YOYO **90.10.35.036**，微信 8.0.80。

用户确认：唤醒不再干扰操作；媒体声音与正常对话共存；锁屏打开计算器无需解锁；0.5 锁屏微信测试无需解锁，消息已发出。

其他环境与任务入口仍属实验兼容范围。曾观察到一次会话切换导致内部确认中止，不保证每次自动应答都成功。

## 安装

安装 APK，在 LSPosed 启用模块，作用域只选 `com.hihonor.magicvoice`，按仓库 README 配置总开关与分项开关，并重新启动 YOYO。

不保存设备密码，不改变系统锁屏，不包含 YOYO/微信 APK、原始设备日志或签名私钥。内部确认音频是系统合成指令，不是用户录音。
